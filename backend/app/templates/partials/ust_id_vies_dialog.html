USt-IdNr. bei VIES pruefen

Das Programm stellt dafuer eine Verbindung zur EU-Schnittstelle VIES auf und sendet eine POST-Anfrage an:

{{ VIES_ENDPOINT }}

Uebertragen wird:

  • Laendercode und USt-IdNr.:
  • Name fuer den Abgleich:
    • {% if requester_vat %}
  • Eigene USt-IdNr. als Anfragender: {{ requester_vat }}
    • {% endif %}

Sichtbar wird fuer die Gegenseite der Abruf selbst, also die IP-Adresse dieses Anschlusses.

Ohne deine Bestaetigung wird keine Internetverbindung zu VIES aufgebaut.
